Update
->	sudo apt update

Upgrade
->	sudo apt upgrade

Update and Upgrade (Updates everything installed via APT)
->	sudo apt update && sudo apt upgrade
	sudo apt update && sudo apt upgrade -y (above - one and the same)

Also want to update kernel + major changes 
->	sudo apt full-upgrade -y

Also remove unused packages
->	sudo apt autoremove -y


Brightness Controller
->	sudo nano /etc/default/grub
->	GRUB_CMDLINE_LINUX_DEFAULT="quiet splash" #(Find and replace by R)
->	GRUB_CMDLINE_LINUX_DEFAULT="quiet splash acpi_backlight=vendor" #(R)
->	sudo update-grub
->	sudo reboot
