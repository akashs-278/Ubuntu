# This file contains all the key board shortcut and modification in `Ubuntu` a `Linux` distribution.

Super = Windows key

## Launchers Section
Home folder
> Super+E

Launch terminal
> Super+T

Settings
> Super+S


## Navigation Section
Hide all normal windows
> Super+D


## Screenshots Section
Record a screencast interactively
> Shift + Super + R

Take Screenshot
> Print

Take Screenshot interactively
> Shift + Super + s

Take screenshot of a window
> F6


## System Section
Open quick settings menu
> Super + W
