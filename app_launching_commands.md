## Google Chrome
Launch New Window
> #### bash
> ---
> ```bash
> google-chrome
> ```

Launch New Incognito Window
> #### bash
> ---
> ```bash
> google-chrome --incognito
> ```

Install
> #### bash
> ----
> ```bash
> sudo apt install google-chrome-stable
> ```

Uninstall
> #### bash
> ----
> ```bash
> sudo apt remove google-chrome-stable
> ```

## VS Code

Open's last used/opened workspace.
> #### bash
> ---
> ```bash
> code
> ```

Open's the particular folder in VS Code.
> #### bash
> ---
> ```bash
> code .
> ```

Open's the particular file in VS Code.
> #### bash
> ---
> ```bash
> code <file_name.extension>
> ```
